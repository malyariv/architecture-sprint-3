
# Задание 1. Анализ и планирование

### 1. Описание функциональности монолитного приложения

**Управление отоплением:**

- Пользователи удалённо могут включать/выключать отопление в своих домах
- Пользователи удалённо могут регулировать температуру в своих домах
- Система поддерживает дистанционное управление датчиков и их регулировку
- Система поддерживает добавление новых устройств

**Мониторинг температуры:**

- Пользователи могут получать информацию о состоянии датчика (вкл/выкл), выставленной на нем температуре и текущей температуре
- Система поддерживает отображении всех датчиков, из состояния и температуры

### 2. Анализ архитектуры монолитного приложения

- **Язык программирования**: Java
- **База данных**: PostgreSQL
- **Архитектура**: монолитная
- **Взаимодействие**: синхронное
- **Масштабируемость**: ограничена, так как монолит сложно масштабировать по частям.
- **Развёртывание**: требует остановки всего приложения.

### 3. Определение доменов и границы контекстов
- управление устройствами
- мониторинг
  - телеметрия
  - видеонаблюдение
- личный кабинет
  - автоматизация (формирование пользовательских сценариев)
  - подписка
- внутрение
  - авторизация
  - отправка уведомлений (отправка пушей и имейлов)
  - биллинг (анализ активности разных устройств и выставление счета пользователю за их использование)
  - платежи (работа с внешними модулями по оплате)

### **4. Проблемы монолитного решения**

- высокий риск ошибок
- длительные циклы разработки и развёртывания
- трудно масштабировать отдельные компоненты системы
- трудно управлять командой
